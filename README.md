# Birthday Princess Card

I want to create an only html+css website as a gift for my girlfiend's birthday.

The goal for the website is a 3d looking one page site that has a little openable card.

The card's pages should look like this:

 - Cover page: A nice cartoonish looking princess tiara and a title: "Happy birthday princess {Her name}"

 - After opening, first page: when opening, a 3d looking nice rose should pop out on the page.

 - After opening, second page: The top and bottom has some nice golden decorative lines and texts between them (I'll fill them out myself)
